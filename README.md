🏥 Hospital Emergency Room Dashboard (Excel)
📊 Project Overview

The Hospital Emergency Room Dashboard is an Excel-based data visualization project designed to monitor and analyze emergency room performance. It provides key operational insights such as patient flow, wait times, admission rates, and case severity, helping healthcare teams improve efficiency and patient care.

🚀 Key Features

Total ER Visits – Overview of patient inflow

Average Wait Time – Monitoring service efficiency

Admission vs Discharge Rates – Patient outcome analysis

Case Severity Breakdown – Critical, moderate, and minor cases

Department-Wise Load – ER workload distribution

Time-Based Trends – Daily and monthly visit patterns

🛠️ Tools & Technologies

Microsoft Excel

Pivot Tables

Pivot Charts

Slicers & Filters

Excel Formulas

📈 Dashboard Insights

Identify peak hours and high-traffic days

Analyze bottlenecks in patient wait times

Track critical case proportions

Support data-driven decision-making for hospital management
